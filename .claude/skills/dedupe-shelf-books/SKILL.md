# Skill: 书架书去重（shelf vs ebook-info + 本地已下载）

判断微信读书**书架书**（`data/shelf_books.txt`）是否：

1. 在**禁止下载列表**（`data/forbid_books.txt`）中，或
2. 已存在于**电子书库**（`data/ebook-info.json`），或
3. 已在本机**导出完成**（默认 `~/data/weixin/books/<book_id>_*.json`），

是则归入 `data/dup_books.txt`（已存在/已下载/禁止），否则归入 `data/new_books.txt`（待导出新书）。

与 ebook-info 的匹配靠**你的语义判断**（书名 + 作者），**不是死板正则、不是字面全等**；与本地已下载的匹配靠 **weread book ID**（文件名前缀），精确可靠。

## 文件

| 文件 / 目录 | 角色 | 格式 |
|------|------|------|
| `data/shelf_books.txt` | 输入：书架书 | 每行 `ID,书名,作者名`；ID 是 weread bookId；多作者用空格连写，常带 `[宋]`/`【清】` 朝代前缀和 `译注`/`评注` 等角色后缀 |
| `data/forbid_books.txt` | 输入：禁止下载 ID | 每行一个 weread bookId；空行与 `#` 注释忽略；也可写 `ID,书名,作者`（只取逗号前 ID）。命中 → **dup**，不进 new；批量导出也会跳过 |
| `data/ebook-info.json` | 输入：电子书库 | JSON **数组**，1333 条左右；每条取 `bookName` 和 `authorName`（其余字段如 `id`/`category` 忽略）。注意其 `id` 是电子书体系的整数 id，**与 weread bookId 不可互通** |
| `~/data/weixin/books/`（或 `BOOKS_DIR`） | 输入：本地已导出书 | 文件名 `{weread_book_id}_{书名}.json`；**只取 `_` 前的 book_id** 组成 `downloaded_ids`。目录可用环境变量 `BOOKS_DIR` 覆盖，默认 `~/data/weixin/books`（与 `export_precise.py` / `env_config.BOOKS_DIR` 一致） |
| `data/dup_books.txt` | 输出：已存在或已下载 | 每行 `ID,书名,作者名`；首次运行不存在则创建 |
| `data/new_books.txt` | 输出：新书（待导出） | 同上；**不应**再包含 `downloaded_ids` 中的书 |

> ebook-info 与 shelf **永远不能靠 ID 对比**，只比书名 + 作者。  
> 本地 `books` 目录文件名里的 ID **就是** weread bookId，**必须**按 ID 精确匹配，不要再做书名模糊比对。

## 处理流程

1. **读输入**：把 `data/shelf_books.txt` 每行按逗号拆成三段 `{ID, 书名, 作者名}`（书名、作者名里不会再有逗号）。
2. **读禁止列表**：加载 `data/forbid_books.txt`（不存在 → 空集）。每行取 weread ID（忽略空行/`#` 注释；含逗号则取首段），汇总成 `forbid_ids`。
3. **读本地已下载**：扫描 `BOOKS_DIR`（默认 `~/data/weixin/books`）下所有 `*.json`，文件名按**第一个 `_`** 切开，前半段为 weread ID，汇总成 `downloaded_ids`。目录不存在 → 视为空集并在汇报里说明；不要报错中止（仍可继续与 ebook-info 比对）。
4. **回扫清理 new_books（重要）**：读 `data/new_books.txt`（不存在则跳过）。凡行首 ID ∈ `downloaded_ids` 的行：
   - 若该 ID **不在** `data/dup_books.txt` → **追加**到 `dup_books.txt`（原样行）；
   - 从 `new_books.txt` **删除**这些行（重写文件，保留其余行顺序）。
   - 这样「先标 new、后导出成功」的书会在下次去重时自动剔除，不会继续出现在待导出清单。
5. **算"已处理集合"**：读（可能已更新的）`data/dup_books.txt` 和 `data/new_books.txt`，取每行**第一个字段**（weread ID），汇总成 `processed_ids`。
6. **只处理新书**：从书架列表里**剔除** ID ∈ `processed_ids` 的行，剩下的才是本轮 `todo`。若 `todo` 为空 → 直接结束，汇报清理结果（若有）与「没有待处理的书」。
7. **读电子书库**：加载 `data/ebook-info.json`，每条只用 `bookName` + `authorName`。
8. **逐本判断**（规则见下）：`todo` 里每本判为 `dup` 或 `new`。
9. **追加写回**（**只追加、不覆盖**，保留两个输出文件原有内容；第 4 步的清理重写除外）：
   - dup 的行 → 追加到 `data/dup_books.txt`
   - new 的行 → 追加到 `data/new_books.txt`
   - 写出的行格式与输入一致：`ID,书名,作者名`（原样取自该 shelf 行，不改写）。
10. **汇报**：禁止列表 N0 本；本地已下载 N 本；本轮从 new 迁到 dup 的 M 本；本轮处理 todo K 本，其中 dup X 本（可再区分「禁止列表 / 已下载 / 命中 ebook-info」）、new Y 本。

## 判断规则

对 `todo` 里每本 shelf 书，按以下**优先级**判定（命中即停）：

### 优先级 0 · 禁止列表（按 weread ID）

- 若 shelf 的 `ID` ∈ `forbid_ids` → **dup**（用户标记为不需要下载；不要放入 `new_books.txt`）。
- 只比 ID，不做书名/作者模糊匹配。
- 文件缺失或为空 → 本关全部不命中。

### 优先级 A · 本地已下载（按 weread ID）

- 若 shelf 的 `ID` ∈ `downloaded_ids` → **dup**（已导出完成，无需再收/再导）。
- 不要用书名去 books 目录里模糊找；文件名 ID 前缀是唯一依据。

### 优先级 B · 电子书库（语义：书名差不多 + 至少一个相同作者）

去 ebook-info 里找是否存在「同一本书」。**核心原则，不要死抠字面：**

> **书名差不多（同一作品）且作者集合有交集（至少一人相同）→ dup。**  
> 标点、括号、冒号、装帧/分册/丛书修饰、空格、半角全角差异，**一律不得单独否决**。

ebook-info 里**任意一条**同时满足下面两关即可。

#### 第 1 关：书名 = 差不多同一作品（语义，非字面全等）

先问：**去掉版本/装帧/分册等修饰后，是不是同一部作品的主书名？** 是 → 过。

**应视为「修饰、可忽略」的差异（出现这些时主体相同仍算过）：**

- 半角/全角括号：`(精装版)` / `（珍藏本）` / `（读客三个圈经典文库）`
- 冒号/破折号后缀：`：全二册` / `:上下` / `——注释本`（与括号里的 `全二册`/`上下册` **等价**）
- 装帧/版本词：`精装版`/`图文版`/`增订版`/`修订版`/`珍藏本`/`典藏本`/`中华经典诗话`/`5册装` 等
- 分册套装写法：`全二册`/`全三册`/`上下册`/`上中下`/`套装`/`第一分册` 等（**在主体相同的前提下**）
- 无关空白、`·`/`—`/`-`、半角全角标点互换

**示例（都应判书名过关）：**

| shelf 书名 | ebook 书名 | 为什么过 |
|------------|------------|----------|
| `长安诗酒汴京花：全二册` | `长安诗酒汴京花（全二册）` | 冒号 vs 括号，都是分册修饰；主体都是「长安诗酒汴京花」 |
| `唐诗选：上下` | `唐诗选（全二册）` | 分册写法不同，主体都是「唐诗选」 |
| `杜甫诗歌鉴赏辞典` | `杜甫诗歌鉴赏辞典（珍藏本）` | 珍藏本是装帧 |
| `骆玉明古诗词课（读客三个圈经典文库）` | `骆玉明古诗词课` | 丛书品牌是修饰 |

**不应算同一本（书名不过关）：**

- **主体作品名 genuine 不同** → 不过（不必再看作者）。
- **同一丛书/连续出版物的不同辑、卷、期、册次** → 不过。  
  例：`乐府学（第十一辑）` ≠ `乐府学（第20辑）`；`中国诗歌研究（第11辑）` ≠ `…（第27辑）`；`词学.第三十六辑` ≠ 另一辑。  
  这类数字/辑次是**身份的一部分**，不是可剥掉的装帧词。
- 仅有个别单字重合、整体不是同一作品 → 不过。

⚠️ **禁止**只做字符串完全相等；也**禁止**只认某一种括号格式。漏掉「冒号分册 / 括号珍藏本 / 丛书名」会把已有电子书误判成 new。  
拿不准「主体是不是同一作品」时，再结合作者：若作者明显同一人且书名高度相似，**倾向判过**。

#### 第 2 关：作者 = 至少一人相同

把两边的作者字符串各拆成「人名集合」，**有交集**就过：

- 拆分符：空格、`；`、`、`、`,`、`，`。
- **朝代标记是注解，不是名字**：`[宋]`、`【清】`、`〔元〕`、`[明末清初]` 等方括号前缀去掉再比。所以 `[宋]周密` ≡ `周密`。
- **编校角色是注解，不是名字**：`著`/`译`/`注`/`译注`/`编`/`编注`/`选注`/`选辑`/`选编`/`评注`/`批`/`校点`/`校注`/`审校`/`整理`/`笺`/`导读`/`插图`/`撰`/`解`/`编著`/`主编` 等后缀去掉再比。所以 `洪亮吉著` ≡ `洪亮吉`，`高林广 译注` ≡ `高林广`。
- 拆完、去注解后，两边人名集合有**任意一个**相同 → 过。
- 机构名（如 `上海辞书出版社文学鉴赏辞典编纂中心`、`中国社会科学院文学研究所`）按整体当一个人名比，去「编著」等角色后缀后相同即可。

### 命中汇总

- **0 命中 → dup**（禁止下载）。
- **否则 A 命中 → dup**（已下载）。
- **否则 B 两关都过 → dup**（ebook-info 已有）。
- **否则 → new**。
- **对 B 的偏差原则**：
  - 书名差不多 + 作者有交集 → **必须 dup**（不要因标点/分册写法不同而漏判）。
  - 书名明显不是同一作品，或作者完全无交集 → **new**。
  - 仅当「是不是同一作品」仍真正说不清时，才倾向 **new**（避免把无关书误吞进 dup）。  
  - 对 0 / A 不适用「拿不准」——ID 对得上就是禁止或已下载。

## 工作示例（均为本仓库真实数据）

### 例 0 · dup（本地已下载，按 ID）

- shelf：`b4432030813abbb04g01095e,阿来讲杜甫成都诗,阿来`
- `~/data/weixin/books/` 下有：`b4432030813abbb04g01095e_阿来讲杜甫成都诗.json`
- ID 命中 `downloaded_ids` → **dup**（不必再查 ebook-info）。

### 例 0b · dup（禁止列表）

- shelf：`deadbeef0813abxxxxg012345,某本不想下的书,某人`
- `data/forbid_books.txt` 含：`deadbeef0813abxxxxg012345`
- ID 命中 `forbid_ids` → **dup**（不进 new；即使本地未下载、ebook-info 也不匹配）。

### 例 1 · dup（朝代标记）

- shelf：`61f32200813ab865dg0125af,词品,[明]杨慎`
- 电子书库有：`词品` / `杨慎`
- 书名完全相等 ✓；作者 `[明]杨慎` 去朝代 → `杨慎`，与电子书 `杨慎` 同 ✓ → **dup**。

### 例 2 · dup（多作者脏数据交集）

- shelf：`b8e32890813ab8259g0195a9,绝妙好词,[宋]周密 查为仁 厉鹗 赵惠俊`
- 电子书库有：`绝妙好词` / `周密 选辑；项絪；查为仁；厉鹗 笺；赵惠俊 整理`
- 书名相等 ✓；shelf 作者集 {周密, 查为仁, 厉鹗, 赵惠俊}（去朝代/角色）与电子书作者集 {周密, 项絪, 查为仁, 厉鹗, 赵惠俊} 交集 = {周密, 查为仁, 厉鹗, 赵惠俊} ✓ → **dup**。

### 例 3 · new（同名异作者，最易判错的陷阱）

- shelf：`...古今词话,[宋]杨湜`
- 电子书库里名为 `古今词话` 的只有：`沈雄`；且本地 books 无此 weread ID
- 书名相等 ✓；但作者 `杨湜` 与 `沈雄` **无交集**（这是两本同名古籍，一宋一清）✗ → **new**。
- 教训：书名相同 ≠ dup，必须作者有交集（除非本地 ID 已下载）。

### 例 4 · dup（角色后缀 + 朝代）

- shelf：`...北江诗话,洪亮吉著 陈迩冬校点`
- 电子书库有：`北江诗话` / `[清] 洪亮吉`
- 书名相等 ✓；shelf 作者去角色 → {洪亮吉, 陈迩冬}，电子书去朝代 → {洪亮吉}，交集 {洪亮吉} ✓ → **dup**。

### 例 5 · dup（冒号分册 ≈ 括号分册，曾漏判）

- shelf：`4a132360813ab9aaeg01862f,长安诗酒汴京花：全二册,随园散人`
- 电子书库有：`长安诗酒汴京花（全二册）` / `随园散人`
- 书名主体都是「长安诗酒汴京花」，`：全二册` 与 `（全二册）` 只是分册写法不同 ✓；作者同为 `随园散人` ✓ → **dup**。  
- 同类：`唐诗选：上下` ≈ `唐诗选（全二册）`（同一选本机构时）→ **dup**。

### 例 6 · 回扫：new → dup（导出完成后）

- 上轮 `new_books.txt` 有：`29432890813ab6dc8g01357c,彦周诗话,...`
- 本轮发现 `~/data/weixin/books/29432890813ab6dc8g01357c_彦周诗话.json` 已存在
- → 该行追加进 `dup_books.txt`，并从 `new_books.txt` 删除；本轮 todo 不再包含它。

## 边界与注意

- **只追加，不覆盖**（第 4 步对 new_books 的删除式重写除外）：写 dup 时追加；写 new 时对「本轮新判定」追加。
- **可重复运行**：以 weread ID 为去重 key。重跑时已出现在 dup/new 任一文件里的 ID 自动跳过；第 4 步保证「已下载但仍在 new」会被清掉。
- **不要用电子书库的 `id` 字段**和 shelf 的 ID 比较——两套体系。  
  **要用**本地 books 文件名里的 weread ID 与 shelf ID 比较。
- **作者/书名两边的字符串都很脏**（ebook-info 路径）：朝代前缀、角色后缀、冒号/括号分册、多种分隔符都可能出现；按「书名差不多 + 作者有交集」原则语义处理，**不要写成只能过某一类正则的死规则**。
- 若 `shelf_books.txt` 或 `ebook-info.json` 不存在 → 停下，提示用户先准备数据，不要凭空生成结果。
- `data/forbid_books.txt` 不存在或为空 → 不中止，视为无禁止 ID。
- 本地 books 目录缺失或为空 → 不中止，仅跳过优先级 A 与第 4 步迁移（并在汇报中写明）。
