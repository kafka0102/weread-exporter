# 双语卷「整段重复目录」排查（2026-10-22）

> 现象：抓 `dc0320a0813ab8c29g0104f7《苏东坡说：苏东坡诗文中的故事》（崔铭 崔诗晨）` 时，
> 会话日志出现「顶栏「亲历故事」/逻辑「原文」」→
> 「逻辑章已在目录末项「原文」，正文仍停在「亲历故事」：判定章节失同步，丢弃脏缓冲并重开会话续传」
> → `❌ 导出失败: 连续重开阅读器仍无法前进（7 次）`、`本次: +0 章, +0 字`。
> 结论：这本书目录是「译文卷 + 原文卷」两个**同名整段**，会话按标题去重的视图把
> 原文卷整段吞掉，于是「原文」成了目录末项，越位防护/末章收尾把正常翻页判成失同步。

## 一、现场

| 证据 | 内容 |
|---|---|
| 中间产物 | `output/dc0320a0813ab8c29g0104f7/chapters` 85 个 md（0001「版权信息」…0085「说谎好累」）、`_catalog.json` 168 项 |
| 失败日志 | 「第 86/84 章」（把目录读成 84 项）、「顶栏「亲历故事」/逻辑「原文」」、「[文末]」、重开 7 次后 RuntimeError |
| 目录形状 | 前 86 项 = 扉页/版权信息/写在前面/文前/译文 + 81 篇（10 个门类 + 71 个故事）；后 82 项 = 原文 + 同样的 81 个篇名**原样重排** |

### 阅读器实测（`.scratch/probe_dc0320_*.py`，只读探针，不入库）

| 读数 | 结果 |
|---|---|
| 目录 DOM 行数 | 168（`.readerCatalog_list_item`），与 `_catalog.json` 一一对应 |
| 目录第 86 项 | 「原文」，DOM 上带 `_selected`（阅读器把「原文」当当前章） |
| 点第 86 项 | 进度 63%→59%，落到「原文」卷首页（画布 0 个：卷首页是 DOM 页），正文首行 `原文 家族往事 高祖父拒学法术［…` |
| 点第 87/100/150/167 项 | 进度分别落到 59%/64%/94%/99%，都是**可跳转**的行 |
| 顶栏（`.renderTargetPageInfo_header_chapterTitle`） | 原文卷的页显示「原文」或门类名（亲历故事/僧道传奇…），**从不显示具体篇名**；`_title()` 取到的往往是书名 |
| 站内章表 `chapterInfos` | `soldOut=1`、`updated` 为空（公版书取不到），章模型只能靠目录 + 正文 |

即：原文卷的 81 篇是**真章节**（可跳转、有文言行），但阅读器顶栏在这半本书里只报卷名/门类名，
所以「按标题查目录」的旧启发式必须靠**唯一标题**才能工作。

## 二、根因：按标题去重的视图把原文卷吞掉了

| 读数 | 值 | 后果 |
|---|---|---|
| `catalog_positions` | 168 项（含原文卷 82 项） | 位置类判断（进度/按序号跳转）没问题 |
| `dedupe_catalog_titles()` | 87 项：…「说谎好累」「原文」 | 原文卷 81 篇被当成「同名重复」丢掉，**「原文」成了末项** |
| `is_last_catalog_chapter("原文")` / `is_export_terminal_chapter("原文")` | `True` / `True` | 末章收尾 + 越位灌末章防护就位 |
| 会话内 `[文末]` 标记 | 出现 | 同上：把中途的正常翻页当成「书末」 |
| 续传锚点 | `(86, "原文")` | 跳转正确；但跳过去之后按去重视图判「已在末章」，正文一翻页就被判「章节失同步」 |
| `resolve_stale_advance_target("原文")` | `None` | 无处可退 → 只能重开 → 重开 7 次 → RuntimeError |

即：**根因不在跳转，而在会话视图的取法**——同一批篇名在书里出现了两次，按标题去重只留第一份，
后一半的章节顺序信息就全丢了（同源问题见 `repeated-chapter-titles-2026-10-20.md` 第六节「旧启发式仍按标题」）。

## 三、修复：按锚点所在段落取会话视图

新增三个 helper（`export_precise.py`）：

| helper | 作用 |
|---|---|
| `repeat_section_start(catalog)` | 找出「整段重复前文」的后段起点（≥`REPEAT_SECTION_MIN_ROWS`=3 项全都能在前文找到同名项）；《苏东坡说》→ 86（「原文」卷名） |
| `session_anchor_index(md_dir, catalog)` | 本会话要续传的那一章在**完整目录**里的序号（磁盘进度之后的下一章；全新导出为 0） |
| `session_catalog_view(catalog, anchor)` | 会话里旧启发式用的视图：锚点在后段 → 取后段（段内标题唯一）；锚点在主段 → 取主段；没有后段/后段标题不唯一 → 保持原去重视图（行为不变） |

接入点：`run_session` 建视图的三处（初始化、`goto_first`、目录兜底重载）改用 `session_catalog_view`。
位置类判断（进度、`disk_resume_target`、`cat_idx=` 跳转、补漏）仍一律用完整目录，不受影响。

效果（对现有产物复算）：

| 读数 | 修复前 | 修复后 |
|---|---|---|
| 会话视图 | 87 项（原文卷消失） | 82 项：原文 + 家族往事 … 说谎好累 |
| `is_export_terminal_chapter("原文")` | `True` | `False` |
| `resolve_stale_advance_target("原文")` | `None` | `家族往事` |
| 主段（译文卷）视图末项 | 原文（后段卷名） | 说谎好累（主段末尾正常收尾，不再飘进原文卷） |

`0087 高祖父拒学法术` → … → `0157 说谎好累`），JSON 158 章、91,683 字；
抽样确认原文卷是文言原文（`［故事原文］苏廷评行状（节选）…`、`［故事原文］作伪心劳…`），
与译文卷的白话改写互不重复；单章最长 2,502 字（2.7%），无「整本灌进单章」。

## 五、遗留

1. **同名拆章**：`祖父豁达不羁` 的原文段被拆成 `0088`（81 字）+ `0089`（922 字）两个同名章
   （正文互补、不丢字）。触发链：原文卷每页都带卷名「原文」（顶栏/运行栏文本），
   顶栏于是恒为「原文」→ 落后于逻辑章「祖父豁达不羁」，正文里又出现更早的「家族往事」——
   回退纠偏（`earlier_catalog_chapter_in_blocks`）据此把缓冲先落盘再回退重抓。属于
   「卷名/门类名出现在正文里」这一采集层老问题（同 `wide-book-chapter-order-2026-10-18.md`
   §6.1 的残留重复），修法是让回退纠偏忽略「已被跳过/无正文的同名页」或要求命中章确有正文。
2. **门类名页不落章**：原文卷的 10 个门类名（家族往事…奇谈怪论）与译文卷同名同内容，
   按「同名章已在磁盘」跳过，成品里不单独成章（只有篇名章）。要保留门类页需另定规则。
3. **顶栏在本类书里不可靠**：阅读器对原文卷只报卷名/门类名（`原文`、`亲历故事`…），
   `_title()` 常退化成书名。会话已尽量靠正文切章（本次实跑 73 章全部由正文切章 + 顶栏辅助完成），
   但顶栏参与的回退/重定位启发式仍有误判空间。
