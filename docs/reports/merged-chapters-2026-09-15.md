## 二、根因：顶栏整本停在书名时，正文永远不会切章

### 症状

词林正韵第一次重抓只得到 13 章：第 8—19 章各自成章，而**第 1—19 章的全部正文
堆进最后一个名为「词林正韵」的章**（8,307 字、15 页）。补漏阶段按目录跳转补齐
了 12 章（`fill_missing_chapters` 有 `max_chapters=12` 上限，且取 `missing[-12:]`，
即先补靠后的章），最终仍缺第 1—7 章。

### 代码路径

`find_chapter_split()` 里：

```python
cur = normalize_catalog_title(current_title)   # 「词林正韵」→ 非空
if cur:
    nxt = next_catalog_title(catalog_titles, cur)  # 不在目录里 → None
    if not nxt:
        return None        # ← 直接放弃，永远不会走「按目录顺序找章首」
```

`normalize_catalog_title()` 只做清洗、不判断是否真在目录里。本书阅读器顶栏整本停在
书名「词林正韵」，清洗后非空 → 被当成「当前章已知」→ `next_catalog_title()` 取不到 →
`return None`。于是 `split_if_next_chapter_started()` 一直返回 False，缓冲只增不减，
直到「无更多新内容」把整本当成一章落盘。

### 离线复现

用重抓前的中间产物复现（`output/acb321205b87ecacbe1c14e/chapters/0013.md` 拆分块，
目录取 `_catalog.json`）：

```text
catalog_index(cat, "词林正韵")            = None
find_chapter_split(blocks, cat, "词林正韵") = None      ← 旧逻辑：永不切章
find_chapter_split(blocks, cat, "")        = ("第1章", 1, 114)  ← 走回落分支则正常
```

### 修复

把「当前章能否定位」的判断从「清洗后是否为空」改成 `catalog_index()` 的结果：
定位不到时（顶栏为空**或**顶栏显示书名/卷名等目录外文本）回落到「按目录顺序找第一个
章首」分支——顶栏为空时原本就走这条，行为不变。

## 三、复核为「不是故障」的两处

- **千古诗心一趣通 171 个「空章」**：目录是「篇章页 + 正文页」成对结构（如
  「伊人宛在水中央」＋「诗经·国风」），篇章页正文只有标题本身，落盘后 `content` 为空。
  171 个空章标题在其它章正文里**一个都找不到**（0/171），后记也自述「一百八十篇左右」，
  与 359 项目录成对吻合。判定：书本身结构如此，非丢正文。
- **中国古典诗文诵读缺的 2 项**：「大学①（节选）」「龟虽寿①」在阅读器里是章节内锚点，
  补漏跳转只落到父章（顶栏分别是「第二章 国学精选」「第四章 励志劝勉」）。这两段正文
  确实已在父章正文中（第二章 1,375 字含「大学（节选）」全文），未丢字。
