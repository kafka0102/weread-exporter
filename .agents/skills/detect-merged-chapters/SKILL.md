# Skill: 已下载电子书章节合并体检

判断一本书的正文是否被堆进单一章节（导出时印刷目录页被当成章首，会把目录一路推到末章，
前几十章只剩标题占位），输出可人工复核的分级清单。

**优先直接跑脚本**，不要临时手写统计：

```bash
python detect_merged_chapters.py
python detect_merged_chapters.py --include-suspect --tsv .scratch/merged-chapters-report.tsv
python detect_merged_chapters.py --books-dir ~/data/weixin/books
python detect_merged_chapters.py --include-output   # 连 output/<id>/chapters 中间产物一起体检
```

脚本**只读**：只打印结果 / 可选写 TSV，不删除、不移动、不修改任何电子书文件。

## 判定规则（脚本已实现）

只看各章正文字数分布（去空白后按字符数），另用「最大章里是否混入其他章名 / 其他章正文」
做交叉印证：

| 情况 | 处理 |
|------|------|
| ≤2 章 | **豁免**：诗词画册、单篇，单章一两万至两三万字属正常 |
| 3—4 章 | **默认不判定**：「版权信息 + 正文 + 附录」天然单章占比高；可用 `--min-chapters 3` 放宽（会误报） |
| 5—9 章 | 单章 ≥70% 且其余多为小章 → 报；≥90% → 严重（上下卷各半属正常，不报） |
| ≥10 章 | 单章 ≥50% 且其余多为小章 → 中度；≥80% → 严重；仅过半但其余章不小 → 可疑 |
| 任意章数 | 最大章占比 ≥30%，且其中确实混入 ≥3 章其他章正文或 ≥10 个其他章名 → 中度（强证据） |
| 任意章数 | 空章 + 标题占位章占比 ≥50% → 「多章无正文」（≥5 章才判定） |

「小章」= 正文字数 < max(200 字, 全书 1%)；「标题占位章」= 正文只有章名本身。
全书不足 5000 字（样本太小）不判定。

## 分档含义

| 分档 | 含义 | 建议 |
|------|------|------|
| 严重 | 单章 ≥80%（或 5—9 章时 ≥90%）且其余章基本是占位章 | 基本可确定是合并，直接重抓 |
| 中度 | 单章过半且其余多为小章，或有强交叉证据 | 抽看一两章正文后重抓 |
| 可疑 | 单章过半，但其余章都有实质正文（默认不列出，加 `--include-suspect`） | 可能只是正常长章 |
| 多章无正文 | 大量空章/标题占位章 | 属于另一类缺失，单独复核 |

输出里的 `最大章为书前/书末项` 是关键提示：占到全书大头的章若是「后记 / 附录 / 索引 /
参考资料 / 版权信息 / 目录」一类，几乎可以确定是合并；若是「卷四」「第七章」这类正文性章名，
再结合 `混入其他章名`、`其他章正文重复` 两列判断。

## 输出

```
[严重] 6ee32660813ab69aeg01341d 唐代文学研究年鉴（2016） 章 67 字 319947 \
  最大章#67/67「2015年唐代文学研究论文索引」占100% 其余小章66(100%) | 混入其他章名62个、空章60个
```

`--tsv <path>` 写出明细表（级别 / book_id / 书名 / 章数 / 总字数 / 最大章序号 / 最大章名 /
占比 / 其余小章数 / 小章占比 / 空章数 / 占位章数 / 最大章为书末项 / 混入章名 / 正文重复章 / 来源）。
`--json` 输出机器可读结果。

## 发现后如何处置（需用户确认后再动）

1. 把命中的 `book_id` 追加到 `data/new_books.txt`（格式 `ID,书名,作者`），可置顶优先抓。
2. 删掉已抓取的产物，否则批量导出会按「已存在 JSON」跳过：
   - `~/data/weixin/books/<id>_书名.json`（成品）
   - `output/<id>/`（中间产物，可保留用于对照）
   删除属于破坏性操作：先确认清单，优先 `mv` 到 `~/.Trash/<批次>/` 而不是直接 `rm`。
3. 用修好的逻辑重抓：`python export_precise.py --no-prefer-largest-screen`（`--force` 可跳过「已有 JSON」检查）。
4. 重抓后再跑一次 `python dedupe_shelf_books.py`，让清单与本地成品保持一致。

## 边界

- 只体检 `~/data/weixin/books/*.json`（可用 `--books-dir` / `BOOKS_DIR` 覆盖）；`--include-output` 才会看中间产物。
- 判定是启发式：短书豁免、5—9 章收紧门槛，但「单章占比高」本身不等于故障，务必人工复核 `可疑` 档。
- 交叉证据（章名混入 / 正文重复）是抽样比对（24 字窗口），命中即说明该章正文里出现了别章内容。
- 规则要改就改 `detect_merged_chapters.py` 与本 skill（`.agents/` 与 `.claude/` 两份保持一致）。
